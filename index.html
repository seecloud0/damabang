1. 스마트폰 홈 화면에 바로 설치하기 (추천)

브라우저(Chrome/Safari) 메뉴에서 [홈 화면에 추가] 또는 [앱 설치]를 누르면 실제 스마트폰 앱처럼 설치되어 주소창 없이 전체 화면으로 사용할 수 있습니다.

2. 구글 플레이스토어에 앱 등록하는 방법

담아방은 표준 manifest.json과 Service Worker를 갖추고 있어 다음 2가지 방법으로 구글 플레이스토어용 .aab 또는 .apk를 1분 만에 만들 수 있습니다:

  • PWABuilder / Bubblewrap: 배포된 URL을 넣으면 구글 플레이용 TWA 안드로이드 패키지 자동 생성
  • Capacitor (안드로이드 스튜디오): npx cap add android 명령어로 즉시 네이티브 안드로이드 앱으로 빌드
